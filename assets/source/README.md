# Native photography sources

Accepted full-resolution generated sources for the Skyriders landing page. These are illustrative capability photographs, not company project records. Files are outside public so visitors receive only optimized responsive derivatives.

- `hero/`: seven descriptively labelled original PNGs. Encoding inputs: `docs/photo-source-inputs.json`; source hashes: `docs/hero-source-integrity.json`.
- `about/`: two labelled portrait PNGs. Encoding inputs: `docs/about-photo-inputs.json`.
- `services/`: the cooling-tower interior photograph. Encoding inputs: `docs/services-photo-inputs.json`; prompt and design notes: `docs/services-design.md`.

Web derivatives live under `public/images/hero/`, `public/images/about/`, and `public/images/services/`. Full built-in imagegen prompts/provenance are recorded in `docs/photography-prompts.md`, `docs/about-photography-prompts.md`, and `docs/services-design.md`. Tool-saved originals remain intact in the original generated-images directory too.
